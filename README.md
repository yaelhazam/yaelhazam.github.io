# Yael Hazam | יעל חזם

האתר האישי שלי, שבניתי כחלק מההגשה למשרת מפתחת אוטומציה ואינטגרציות בקבוצת תמוז.

**לצפייה:** https://yaelhazam.github.io

## מה יש באתר
- **מוצא מידות לקרוקס:** אב-טיפוס שמקבל אורך ורוחב של כף הרגל ואת סוג השימוש, ומחזיר מידה, דגם והסבר. הנתונים נאספו מ-12 דגמים באתר WeShoes.
- **אותה תשובה, שני ראשים:** התשובה של הכלי מוצגת כ-JSON שאפשר לערוך, ולצידה פוסטר של קבוצת תמוז שמשתנה לפי הערכים.
- **ג׳יביטס:** הכישורים שלי בתור ג׳יביטס שאפשר לגרור בין החורים בכפכף.
- עברית ואנגלית, מצב בהיר וכהה, ותצוגה מותאמת לנייד.

## איך זה בנוי
HTML, CSS ו-JavaScript נקי, בלי ספריות ובלי שלב בנייה.

```
index.html   המבנה והתוכן
style.css    העיצוב
script.js    לוגיקת המידות, ה-JSON, הפוסטר והג׳יביטס
images/      תמונות
files/       קורות החיים ב-PDF
```

## הרצה מקומית
פותחים את `index.html` בדפדפן, או משתמשים בתוסף Live Server ב-VS Code.
